# Atmosphere Desk

A weather dashboard with live conditions, forecasts, air quality, and quick actions.

## Run locally

- Open index.html in your browser
- Add your OpenWeather API key in app.js

## Features

- City search with suggestions and voice input
- Current conditions, forecasts, air quality, alerts
- Favorites and recent search history
- Theme + units settings with persistence

## Deploy (GitHub Pages)

1. Create a GitHub repository and push this project.
2. In GitHub, open Settings -> Pages.
3. Under Build and deployment, choose Deploy from a branch.
4. Select the main branch and / (root) folder.
5. Save, then open the provided Pages URL.

Tip: make sure index.html is in the repository root.
